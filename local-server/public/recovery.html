If you forgot a password, reset it on the restaurant server PC, or use a GTCT support recovery key when that is enabled.

On the restaurant PC

  1. Open Reset Staff Password from the Start menu (GTCT), or run the reset command in a terminal on that PC.
  2. Choose the username (for example admin).
  3. Enter a new password (letters and numbers, at least 8 characters).
  4. Return here and sign in.

Command (developer / unpackaged): npm run admin:reset-password

GTCT support recovery

Enter the support master key for this shop, then set a new password.

Support master-key recovery is not enabled on this PC. Use the restaurant PC reset tool above.
